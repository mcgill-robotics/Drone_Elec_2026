# Drone electrical 2025/26 repo
There are 4 sections to this repository:
<br>
1. **pcb_hardware** documents the hardware system overview of the drone and explain the purpose of each pcb.
2. **PX4_Parameters** revision controlling the settings of the flight controller software PX4 we use for flying the drone
3. **STM32_Firmware** is the firmware for the pcb's with ic's onboard
4. **STM32_Test_Code** is simple firware to ensure all board features are working after assembly
